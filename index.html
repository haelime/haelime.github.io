01 · Graphics Engine C++ / Vulkan / GLSL

VestaEngine

실시간 렌더링부터 path tracing, Gaussian splatting, GPU 프로파일링까지 하나의 런타임에서 관찰할 수 있는 Vulkan 렌더링 엔진입니다.

핵심 구현
  • 명시적 render pass와 resource transition을 기록하는 render graph
  • Deferred rasterization, path tracing, hardware ray tracing 경로
  • GPU timestamp, resource, barrier 상태를 확인하는 ImGui 디버그 UI
02 · Multiplayer Unity / C# / TCP

Clasher

Unity 클라이언트와 C# authoritative 게임 서버, 로그인·매칭 서버로 구성한 실시간 1대1 전략 게임 프로토타입입니다.

핵심 구현
  • 100ms 서버 틱 기반 인게임 판정과 승패 처리
  • 소환 위치, 비용, 중복 액션을 서버에서 검증
  • 매칭 티켓으로만 게임 입장을 허용하는 인증 흐름
03 · GPU Simulation Unity / Compute Shader

GPU Boids

Boids 계산을 GPU로 옮기고 indirect instancing을 적용해 많은 에이전트를 실시간으로 제어하는 군집 시뮬레이션입니다.

핵심 구현
  • 시뮬레이션 상태를 GPU 메모리에 유지해 CPU 왕복 최소화
  • Compute Shader 기반 힘 계산과 위치 적분
