## 요약

신입 C++/C# 프로그래머입니다. Unity 기반 게임, C# 및 HLSL 기반 GPU 시뮬레이션, C 기반 광선 추적기를 개발했으며, 자율주행 실무 6개월 동안 FSM 제어 로직과 감시 및 복구 모듈을 구현해 실시간 시스템 개발 경험을 쌓았습니다.

## 경력

### 주식회사 웨어러블에이아이

**시스템 소프트웨어 엔지니어 / 주임연구원**  
2024.11 - 2025.04 (6개월)

#### 인천국제공항 제2여객터미널 자율주행 셔틀 시스템 개발

인천국제공항 제2여객터미널 내에서 운행되는 자율주행 셔틀의 차량 시스템 개발에 참여했습니다. C++/ROS2 기반 주행 제어 FSM과 감시 및 복구 모듈을 구현해 시스템 안정성을 확보했고, Python/PyQt로 LiDAR 데이터 시각화 도구를 제작해 현장 디버깅 절차를 개선했습니다.

### 주요 업무 및 성과

#### 자율주행 FSM 제어 로직 설계

`C++` `ROS2`

- 승객 탑승, 주행, 회피, 비상 정지 등 복잡한 공항 시나리오를 처리하는 최상위 제어 모듈을 구현했습니다.
- 객체 지향 원칙을 적용한 FSM 설계로 상태 간 전이 로직의 유지보수성과 확장성을 확보했습니다.
- 센서 오작동 등 예외 상황 발생 시 즉시 안전 모드로 진입하는 이중 고장 안전 절차를 구현했습니다.

#### 시스템 상태 점검 및 복구 모듈 개발

`C++` `ROS2`

- 다중 프로세스 환경에서 각 노드의 생존 신호를 감시하는 실시간 진단 시스템을 구축했습니다.
- 프로세스 응답 지연이나 비정상 종료 감지 시 자동 복구와 알림으로 이어지는 흐름을 구현했습니다.
- 소프트웨어적 결함을 조기에 차단하여 공항 시운전 기간 중 셔틀 멈춤 사고 예방에 기여했습니다.

#### 2D LiDAR 데이터 시각화 및 검증 도구 개발

`Python` `PyQt`

- 현장 디버깅 효율을 위해 LiDAR 포인트 클라우드를 2차원 평면에 실시간 렌더링하는 경량 도구를 제작했습니다.
- 기존 분석 도구를 대체하여 현장 시험과 로그 분석 소요 시간을 줄였습니다.
