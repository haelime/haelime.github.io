miniRT는 C로 구현한 CPU ray tracer입니다. 카메라에서 광선을 생성하고, 기하 primitive와의 교차점을 구한 뒤 조명과 그림자를 계산하는 전체 과정을 직접 구현했습니다.

![miniRT rendered scene](/assets/img/projects/minirt/result.png)

## Ray Tracing Engine

- 구, 평면, 원기둥, 삼각형과의 ray intersection
- mirror surface를 위한 제한 깊이의 recursive reflection
- 광원별 visibility를 검사하는 shadow ray
- 가장 가까운 교차점과 material을 선택하는 hit pipeline

## Phong Lighting

표면의 최종 색은 세 가지 조명 성분을 조합해 계산합니다.

- **Ambient:** 직접광이 없는 영역의 기본 밝기
- **Diffuse:** Lambert cosine law 기반 확산광
- **Specular:** view와 reflection vector를 이용한 highlight

## Camera

FOV를 기준으로 화면 pixel마다 camera ray를 생성합니다. local, world, camera space 변환을 구성하고 keyboard 입력으로 카메라 위치와 방향을 실시간 조작할 수 있게 했습니다.

## SIMD Optimization

행렬과 vector 연산의 처리량을 높이기 위해 SSE/AVX intrinsic을 사용했습니다.

- AVX 256-bit register로 여러 `float` 동시 처리
- SSE 128-bit register에 `xyzw` 좌표 저장
- 구조체를 64-byte boundary에 정렬해 cache line 활용
- dot product intrinsic으로 곱셈과 누적 연산 처리

```c
typedef struct __attribute__((aligned(64))) s_matrix
{
    float m[16];
} t_matrix;
```

## 해결한 문제

### 유한 원기둥 교차

무한 원기둥의 측면 교차와 위·아래 뚜껑 교차를 별도로 계산했습니다. 측면 교차점은 높이 범위로 clipping하고, 모든 후보 중 가장 가까운 양의 `t`를 선택했습니다.

### SIMD Memory Alignment

정렬이 보장되지 않은 memory를 AVX load instruction에 전달하면 segmentation fault가 발생했습니다. 구조체와 동적 할당 주소를 명시적으로 정렬하고, cache line 크기에 맞춘 layout으로 수정했습니다.
